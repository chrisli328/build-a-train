# Build A Train (playtest site)

Portrait mobile game: an armoured train rolls through the snow while its rooftop crew shoots the zombie horde. You
pick the track at each fork, choose 1 of 3 upgrades as you level, and beat the boss at the end of the line.

- Play the Unity build: https://chrisli328.github.io/build-a-train/
- Every UI screen and popup: https://chrisli328.github.io/build-a-train/ui/
- The original HTML prototype (frozen 2026-11-17): https://chrisli328.github.io/build-a-train/html/

Best on a phone held upright. Store prices and ads are placeholders. The Unity build is commit b5f677a (2026-11-18) of
the game repository; this site is rebuilt from it with Tools/publish-web/publish.sh, do not edit it by hand.
